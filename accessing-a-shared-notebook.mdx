title: How to Access a Secure Mind Dump Document
---
You have been sent a secure, encrypted document created in **Mind Dump**.

Mind Dump uses **Zero-Knowledge, End-to-End Encryption**. This means the document was scrambled on the sender’s device before being sent, and our servers cannot read it. Only you—holding both the web link and the secret passcode—can unlock and view the contents.

## Why You Received Two Separate Messages

To keep this document completely safe, the sender should have sent you two things through **two different channels** (for example, the web link via email, and the passcode via SMS or telephone):

1. **The Web Link:** This opens the document page and contains a hidden, secure fragment that your browser uses to unlock the data.
2. **The Passcode:** The secret alphanumeric key chosen by the sender (e.g. `Summer2026`).

> **Why split them?** If someone manages to intercept the link in an email, they still cannot read a single word of the note without the passcode you received separately.

## Step-by-Step: Unlocking the Document

1. **Open the Link:** Click or paste the web link into your web browser.
2. **Enter the Passcode:** When prompted, type the passcode provided by the sender.
3. **View the Note:** Your browser will instantly decrypt the document right on your screen.

You do not need an account or any special software to view the document.

## Important Security Rules to Keep in Mind

- **3-Attempt Limit:** To prevent unauthorized guessing, entering an incorrect passcode three times will temporarily lock access for 5 minutes. Please double-check your passcode before submitting.
- **Burn on Opening Notes:** If the sender enabled **Burn on Opening**, the encrypted document is permanently destroyed on the server the moment you open it. Make sure to read or copy any important information before closing your browser tab, as the link will not work a second time.
- **Expired Links:** If the sender set an expiration date and that time has passed, the document will no longer be available.
- **Deleting the Share:** Once you have finished reading, you can click **Delete Share** on the screen to instantly remove the record from the server for good.

## ⚠️ Note on Link Permanence

The web link you received contains a unique, one-time cryptographic code (the hash fragment) generated specifically for this shared snapshot.

Mind Dump’s zero-knowledge security means this code is **never stored on our servers**. If you lose or delete the link, the sender cannot "re-send" or recreate the same link. They will have to delete the original share and generate a completely new one for you.
